## 功能介紹

### 地圖頁 `/map`
- 顯示所有有座標的收藏，自動縮放到全部標記。
- 圖例就是開關：❤️ 收藏、📌 想去、✅ 去過、📍 其他、🚫 不推薦（預設不顯示），各自顯示數量。
- 點標記：店名、地區、料理、狀態、評分、「查看詳細」。
- 「我的位置」：定位後飛到目前位置並顯示藍點。
- 「有 N 間店還沒有座標」→「用地址補上座標」：逐間查詢（每秒一間），顯示進度、可停止；完成後列出「用店名找到、建議確認」與「找不到」的店。
- 沒有任何店時顯示引導，連到 AI 找美食。

### AI 找美食的地圖模式
- 推薦完成後出現「列表／地圖」切換。
- 地圖顯示：搜尋範圍圓圈、✨ AI 推薦新店、**範圍內所有有座標的收藏**（依狀態顯示標記，不推薦的不顯示）。AI 挑中的收藏，Popup 會附 AI 評語。
- ✨ 的 Popup：符合度、距離、為你推薦、推薦原因、「📌 加入想去」、在 Google Maps 確認。加入後標記立刻變成 📌。

### 編輯頁「用地址找座標」
- 有地址，或有店名＋城市／地區才能找；找到後帶入經緯度，並提示是依地址還是依店名找到。

## ⚠️ 踩到的問題與修正

- **CARTO 底圖要 API 金鑰了**：計畫用 CARTO Voyager（顏色較柔和），實際載入後整張地圖都是「API KEY REQUIRED」浮水印。改用 **OpenStreetMap 標準圖磚**（也就是 Step 0 決定的 Leaflet＋OpenStreetMap），再用 CSS `filter` 只把底圖調淡（降低飽和度），配合系統的柔和色調，標記不受影響。
  - 用 curl 測 OSM 圖磚會拿到「Access blocked」，那是因為 curl 沒有瀏覽器會帶的標頭；實際在瀏覽器中 15 張圖磚全部 200。
- **Nominatim 看不懂台灣地址寫法**：`813高雄市左營區孟子路587號`、`高雄市左營區孟子路587號` 都查不到，`孟子路 587, 左營區, 高雄市`（由小到大、逗號分隔）才查得到，而且精確到店家（place_rank 30）。新增 `TaiwanAddress` 轉換：拿掉郵遞區號，依「路街（含段、巷、弄）門牌 → 行政區 → 縣市」重組。沒加之前，第一個測試案例其實是靠店名才找到的。
- **AI 結果地圖顯示了不推薦的店**：和收藏區規則不一致，改成不顯示。
- **antd 6 棄用 `Modal` 的 `maskClosable`**：改用 `mask={{ closable: false }}`。
- 一度以為 AI 結果地圖的範圍圓圈偏移，其實是截圖只截到可視範圍、地圖下半部被切掉；改截地圖元素本身確認置中正確。仍保留「切換到地圖時先重新量尺寸再縮放」（`invalidateSize`），避免容器尺寸未定案時縮放錯位。

## 刻意的取捨與已知限制

- **OSM 圖磚是志工維運的公益服務**，使用政策不允許大量使用；個人使用沒問題，若日後公開給多人使用，應改用付費或自架圖磚。
- 用店名找到的座標可能是同名的別間店，所以畫面會特別提醒確認。
- 批次補座標受 Nominatim 每秒一次限制，100 間約需 2 分鐘。
- 店家詳細頁小地圖、在地圖上點選位置這次沒做（使用者未選）。
