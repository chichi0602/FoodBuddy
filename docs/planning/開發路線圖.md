## 整體技術決策（Step 0 與使用者確認）

| 項目 | 決定 | 原因 |
|------|------|------|
| 前端 | React + Vite + TypeScript + Ant Design | 使用者指定 React 與 antd；實際安裝到的是 antd v6 |
| App 形式 | 響應式 Web App | 手機與電腦都能用，不必另做原生 App |
| 「我的美食」資料 | 存在瀏覽器 IndexedDB | 個人使用、最快看到成果；透過 repository 包裝，未來可換成後端資料庫 |
| AI | Azure OpenAI（gpt-5 系列） | 使用者提供金鑰 |
| 金鑰存放 | ASP.NET Core 後端從設定讀取，現為 .NET User Secrets | 金鑰不進前端、不進 git |
| 地圖與店家資料 | Leaflet + OpenStreetMap | 免費、免金鑰（Phase 6 曾改用 CARTO 底圖，因需金鑰改回 OSM 圖磚） |
| 視覺 | 使用者提供的五色配色＋粉圓體 | 見 [設計系統](../architecture/設計系統.md) |
| 版本控制 | 每個階段驗收後才 commit | 使用者要求 |
