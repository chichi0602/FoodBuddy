# 啟動與停止系統

- 文件狀態：維護中
- 對應階段：Phase 5
- 最後核對日期：2026/10/06

## 需要的環境

- .NET 8 SDK（`dotnet --list-sdks`）
- Node.js（開發時使用 v24）與 npm

## 一鍵啟動（Windows）

雙擊專案根目錄的 [start.bat](../../start.bat)：

1. 檢查 `dotnet` 與 `npm` 是否存在
2. 第一次啟動時自動執行 `npm install`
3. 開兩個視窗：「FoodBuddy 後端」（`dotnet run --launch-profile http`）與「FoodBuddy 前端」（`npm run dev`）
4. 前端就緒後自動開啟瀏覽器 http://localhost:5173

**停止**：關掉「FoodBuddy 後端」與「FoodBuddy 前端」兩個視窗。

## 手動啟動

```bash
# 後端（http://localhost:5122）
cd server/FoodBuddy.Api
dotnet run --launch-profile http

# 前端（http://localhost:5173，/api 會轉發到後端）
cd client
npm install
npm run dev
```

## 連接埠

| 連接埠 | 用途 |
|------|------|
| 5122 | 後端 API |
| 5173 | 前端開發伺服器 |

⚠️ 如果 5173 已被占用，Vite 會自動改用 5174、5175…，視窗裡會顯示實際網址。重複執行 `start.bat` 前，請先關掉上一次開的兩個視窗。

## ⚠️ 改版後一定要重開後端

前端存檔後會自動更新，但**後端不會**。拉了新程式或做完新的 Phase 之後，請關掉後端視窗再重新啟動。

沒有重開時的典型症狀：AI 找美食顯示「後端還沒有 AI 功能，請重新啟動後端後再試」（舊後端沒有新 API，回應 404），或新功能沒有出現。

## 確認運作正常

- 打開 http://localhost:5122/api/health，應看到 `{"status":"ok","aiConfigured":true}`。
  `aiConfigured` 是 `false` 表示沒讀到 Azure OpenAI 設定，AI 會改用示範資料（見 [金鑰與設定檔](金鑰與設定檔.md)）。
- 開發環境另有 Swagger：http://localhost:5122/swagger

## 建置

