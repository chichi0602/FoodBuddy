## 一、目標與範圍

Agenda 第 12、13 節：在地圖上看自己的收藏與 AI 推薦，用不同標記區分狀態，並在 AI 搜尋時看出附近有哪些以前收藏的店。

- 範圍：地圖頁、AI 找美食的地圖模式、用地址或店名補座標。
- 非範圍（規劃中）：店家詳細頁小地圖、在地圖上點選或拖曳設定位置、路線規劃。

## 三、標記

| 標記 | 意義 |
|------|------|
| ❤️ | 收藏或想再訪 |
| 📌 | 想去 |
| ✅ | 已去過 |
| 📍 | 沒有標任何狀態 |
| 🚫 | 不推薦 |
| ✨（teal 底） | AI 推薦的新店（尚未收藏） |

一間店多個狀態時只顯示一個標記，優先序：🚫 > ❤️ > 📌 > ✅ > 📍。

底圖使用 OpenStreetMap 標準圖磚，以 CSS 調淡飽和度；右下角標示 © OpenStreetMap 貢獻者。

## 四、地圖頁

- 顯示所有**有座標**的收藏，進入時自動縮放到全部標記；沒有任何店時顯示引導。
- **圖例即開關**：各種標記可分別顯示／隱藏，按鈕上顯示數量；預設隱藏 🚫。
- **Popup**：店名、地區、料理、狀態、評分、查看詳細。
- **我的位置**：需要定位權限，定位後顯示藍點並移過去；失敗時提示原因。
- **沒有座標的店**：提示數量，可「用地址補上座標」
  - 逐間查詢，每秒一間（地圖服務限制），顯示進度，可隨時停止
  - 完成後列出「用店名找到的店（建議確認）」與「找不到的店」
  - 補上的座標不會改變店家的「最近更新」時間

## 五、AI 找美食的地圖模式

- 推薦完成、且有搜尋範圍時出現「列表／地圖」切換；地圖模式時隱藏收藏區與推薦卡片。
- 顯示：搜尋範圍圓圈（虛線）、✨ AI 推薦新店、範圍（半徑 × 1.2）內所有有座標的收藏（不推薦的除外）。
- 上方說明範圍與各種標記的數量。
- ✨ Popup：符合度、距離、為你推薦、推薦原因、「📌 加入想去」、在 Google Maps 確認；加入後標記立即變成 📌。
- 收藏的 Popup：同地圖頁；AI 挑中的收藏另附 AI 評語。

## 六、用地址找座標

| 情況 | 結果 |
|------|------|
| 有完整地址 | 先把台灣地址轉成 Nominatim 格式查詢（例如 `813高雄市左營區孟子路587號` → `孟子路 587, 左營區, 高雄市`），再試原始寫法 |
| 地址查不到，但有店名 | 用「店名, 行政區, 城市」查詢，並提醒使用者確認 |
| 只查到行政區或城市 | 視為找不到（避免把店釘在區公所） |
| 找不到 | 提示可改貼 Google Maps 網址 |

入口：編輯頁「位置」卡片的「用地址找座標」、地圖頁的批次補座標。
