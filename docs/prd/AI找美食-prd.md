# AI 找美食 PRD

- 文件狀態：已實作
- 對應階段：Phase 3～6
- 最後核對日期：2026/10/06

## 一、目標與範圍

Agenda 第 6～11 節：使用者用自然語言提出需求，AI 解析條件、搜尋「我的美食」與真實店家資料、分析排序，並依來源分區呈現。
收藏不是使用門檻：沒有收藏也能用，有收藏時推薦會更貼近口味。

- 範圍：需求解析、OpenStreetMap 真實店家、AI 挑選與分析、收藏比對、口味摘要、三區結果、加入我的美食、搜尋歷史。
- 非範圍（規劃中）：到訪紀錄影響推薦（Phase 7）、Recommendation Score 與主動推薦（Phase 8）。

## 三、流程

```
輸入需求
  → AI 解析條件（約 3～4 秒，畫面先顯示條件）
  → 需求沒有地點時取得瀏覽器定位
  → 後端：地名轉座標 → 查詢範圍內真實店家 → 選出範圍內的收藏
  → AI 依需求與口味挑選、分析（約 15～35 秒）
  → 分三區顯示
```

## 四、畫面

### 1. 搜尋區
- 輸入框（最多 500 字），沒有搜尋時顯示最近 5 筆搜尋。

### 2. AI 理解的需求
- 一句話摘要＋條件標籤：📍地區、🏷地標、🍽料理、🕒時段、👥人數、💰預算、#關鍵字。
- **按 × 移除任一條件就重新推薦**（不重新解析）。移除地區後會改用定位。

### 3. 我的收藏符合條件
- AI 回來前先用地區與料理比對立即顯示；回來後換成 AI 挑過的收藏，每張卡片上方附 AI 評語。
- 選取規則：有座標的收藏要在搜尋範圍（半徑 × 1.2）內；沒座標的比對城市與行政區（「高雄」＝「高雄市」、「臺」＝「台」）；定位搜尋時沒座標的收藏不列入；**不推薦的店不列入**。
- 卡片可直接評分、切換狀態。

### 4. AI 推薦新店
- 搜尋範圍說明：「以『左營區』為中心 2.5 公里內，從地圖資料找到 N 間相關店家」。
- 口味摘要列（收藏 ≥ 3 間時）：「AI 參考了你的口味：拉麵、日式、常見價位 $200～500」。
- **根據你的口味推薦**：AI 判斷明顯符合使用者口味的新店，卡片有「為你推薦」說明。
- **AI 網路探索**：符合需求但與口味無關的新發現。
- 沒有內容的小區不顯示；結果少於 5 間時顯示說明。
- 「換一批」只更換新店，收藏區不變。

### 5. 地圖模式（Phase 6）
- 推薦完成後可在「列表／地圖」之間切換。地圖顯示搜尋範圍圓圈、✨ AI 推薦新店、範圍內有座標的收藏（不推薦的除外），✨ 的 Popup 可直接加入想去。詳見 [地圖 PRD](地圖-prd.md)。

### 推薦卡片內容
店名、地圖已驗證、距離、店家類型、價格、符合度（0～100）、料理標籤、為你推薦（若有）、推薦原因、地址、營業時間、電話、官方網站、推薦餐點、網路評價、優點／可能缺點、加入想去／加入收藏／標記去過（已收藏則顯示狀態與「查看」）、在 Google Maps 確認。

## 五、規則

| 議題 | 規則 |
|------|------|
| 店家從哪來 | **只推薦 OpenStreetMap 上的真實店家**。AI 以 id 從候選清單挑選，schema 用 enum 限定，伺服器再驗證一次；不足 5 間就少顯示，不用 AI 知識補 |
| 搜尋範圍 | 地標或目前位置 1.5 km、行政區 2.5 km、只有城市 4 km |
| 候選排序 | 店名含使用者關鍵字 > OSM 料理標籤相符 > 分類的一般店名提示 > 其他，再依距離；送給 AI 前 40 間 |
| 資料分工 | 店名、座標、地址、營業時間、電話、網站來自 OSM；評價、推薦餐點、推薦原因來自 AI，AI 不認識的店不寫評價 |
| 已收藏的店 | 不會出現在新店（同名，或名稱互含且 100 公尺內），包含不推薦的店 |
| 連鎖店 | 同名的不同分店只留分數最高的一間 |
| 口味摘要 | 權重：想再訪 3、收藏 2、評分 ≥4 加 2、去過 1、想去 1；收藏少於 3 間不送 |
| 送給 AI 的個人資料 | 收藏的店名、座標、城市、行政區、料理、狀態、評分、價格區間；**個人備註與照片不送出** |
| 沒有地點 | 使用瀏覽器定位；拒絕定位時提示「在需求中加上地點，例如高雄左營想吃拉麵」 |
| 沒有金鑰 | 改用示範模式：規則解析＋依料理與距離排序真實候選，畫面顯示「目前顯示的是示範資料」 |
| 搜尋歷史 | 存在 IndexedDB `searchHistory`，同一句只保留最新一筆 |

## 六、錯誤訊息

| 情況 | 顯示 |
|------|------|
| 後端沒開 | 連不上 FoodBuddy 後端，請確認後端已啟動 |
| 後端是舊版（404） | 後端還沒有 AI 功能，請重新啟動後端後再試 |
| 金鑰或 Endpoint 錯誤 | Azure OpenAI 驗證失敗，請確認 ApiKey 與 Endpoint 設定 |
| 部署名稱錯誤 | 找不到 Azure OpenAI 部署，請確認 Endpoint 與 Deployment 名稱 |
| 地點找不到 | 找不到「XX」這個地點，請換個說法或加上城市名稱 |
| 地圖服務忙碌 | 地圖店家資料服務暫時忙碌，請稍後再試 |

錯誤訊息旁有「再試一次」。
