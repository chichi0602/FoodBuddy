## 一、配色

使用者提供五個顏色，另外衍生兩色。定義在 [theme.ts](../../client/src/theme/theme.ts)（antd token）與 [index.css](../../client/src/index.css)（CSS 變數）。

| 名稱 | 色碼 | CSS 變數 | 用途 |
|------|------|------|------|
| sky-light | `#A6DAEC` | `--sky-light` | 強調底色、收藏評語便條、AI 區的次要文字（深底上） |
| sky | `#82BFD3` | `--sky` | hover 邊框、「想去」狀態色 |
| teal（主色） | `#386E80` | `--teal` | antd `colorPrimary`、主要按鈕、首頁對話區底色 |
| charcoal | `#636166` | `--charcoal` | 主要文字 |
| gray | `#8D8D8F` | `--gray` | 次要文字、提示、「不推薦」狀態色 |
| teal-deep（衍生） | `#244A57` | `--teal-deep` | 頂部標題列、標題文字 |
| mist（衍生） | `#F3F8FA` | `--mist` | 頁面背景 |

## 二、字型

- 全站使用 **Huninn（jf 粉圓）**，由 Google Fonts 載入（[index.html](../../client/index.html)）。
- 選擇原因：使用者要求「可愛、圓滑、柔和」；Huninn 是 Google Fonts 上為繁體中文設計、字集完整的圓體，不會缺字。
- ⚠️ **只有一種字重**：設定 `font-synthesis-weight: none`，禁止瀏覽器硬加粗（會模糊）。標題用字級與深 teal 建立層次，不用粗體。
- 後備字型：微軟正黑體、蘋方。

## 三、形狀與版面

- 圓角：一般元件 12px、卡片與區塊 20px、標籤與膠囊按鈕全圓。
- 主要入口（首頁「今天想吃什麼？」、AI 找美食搜尋區）用 teal 底＋右上淡藍光暈，是全站唯一大面積色塊。
- 電腦版（≥ 768px）：左側 208px 選單，內容最大寬 1200px。
- 手機版：底部 64px 分頁列，內容左右留 16px。
- 卡片列表用 CSS Grid `auto-fill`，手機改單欄。

## 四、可及性

- 鍵盤焦點：`:focus-visible` 顯示 2px teal 外框。
- 使用者設定減少動態時（`prefers-reduced-motion`）關閉動畫。
- 狀態按鈕帶 `aria-pressed`，圖示按鈕帶 `aria-label`。
